Retractable Mid-Platform Railway Crossing System with Multi-Sensor Train Detection

Invention Disclosure Form

Abstract

This project presents a Retractable Mid-Platform Railway Crossing System designed to enhance accessibility and reduce unsafe track trespassing. The system uses an Arduino-controlled ultrasonic sensor to monitor train proximity and servo-driven actuators to extend or retract a sliding deck. Piezoelectric tiles harvest energy from footsteps to support low-power station utilities.

Present State of the Art

Typical solutions include Foot Over Bridges (FOBs), underpasses, warning alarms, CCTV and platform screen doors for metro systems. These approaches face accessibility, cost and trespassing challenges; mid-platform deployable crossings are not commonly used.

Problem Addressed & Proposed Solution

The system reduces illegal track crossing, improves access for elderly and disabled passengers, and integrates renewable energy. A sliding deck deploys only when no train is approaching and retracts automatically on train detection; a manual override is provided for emergencies.

Detailed Explanation

Working Principle

  1. Normal: deck retracted, barricades locked.
  2. Safe verification: ultrasonic (or multi-sensor) checks distance.
  3. Deployment: Arduino drives servos to extend deck; piezo tiles provide auxiliary power.
  4. Train detection: warnings activate; deck retracts and locks.
  5. Fail-safe: system defaults to retracted and locked during faults.

Manual Backup System

Pinion gears, connecting chain and a rotating lever enable authorized staff manual operation.

Working Examples

Example 1 — Normal Operation

Sensor confirms safety, sliding deck deploys, passengers cross, train detected, deck retracts.

Example 2 — Power Failure

System remains locked in fail-safe; staff operate manual override if required.
